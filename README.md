# MailGuard

MailGuard is a PHP and Python–based internal messaging system with built-in risk analysis and AI-text detection.  
It allows registered users to send, receive, and read messages inside the application while automatically analyzing message content for suspicious patterns and AI-generated text.

The project focuses on **transparent, explainable scanning logic** rather than black-box models.

---

## Features

- User authentication (signup / login)
- Internal inbox and sent mail
- Full-screen message view
- Clickable inbox and sent rows
- Rule-based threat detection with risk scoring
- AI-text heuristic detection with confidence percentage
- Visual indicators for Allowed / Flagged / Blocked messages
- Configurable risk thresholds and keywords
- PHP frontend with Python analysis engine
- MySQL database storage

---

## Tech Stack

- **Frontend:** PHP, HTML, CSS  
- **Backend:** PHP (PDO), Python  
- **Database:** MySQL / MariaDB  
- **Analysis Engine:** Python (regex + heuristic-based logic)  
- **Environment:** XAMPP (Apache + MySQL)
